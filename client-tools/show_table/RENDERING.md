# show_table

Rows of the same shape as a table: its title, the columns in order under their labels, a line per row, each cell the row's value under its column's key.

## Reply

None: it only shows.

## In traceflow's apps

Table: a white panel with the title, a plain table (caption header, hairline rows), and "n more rows" when capped.

## On a channel without UI

The title, then the first 10 rows as `- Label: value · Label: value`, then "and n more" when there are more.
