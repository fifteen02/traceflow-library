# update_plan

The plan the agent is working through, whole: its title and steps as `show_plan`'s. The latest call is the plan, pinned above the person's chat.

## Reply

None: it only shows.

## In traceflow's apps

The latest plan pinned above the chat, drawn as Plan is.

## On a channel without UI

No drawing of its own: its arguments as labelled fields (each argument's name made readable, values joined by commas), headed by the call's description.
