# show_file

A file of the thread's workspace (`path`, relative to it), titled `title` or its name.

## Reply

None: it only shows.

## In traceflow's apps

Nothing for the call itself: the file travels on the reply, drawn by its kind: Report for a document, Deck for slides, Photo for an image, a voice note for audio. The console's web app draws the call as a card with the file's name, size, a preview (a web page live, an image, audio to play, the start of a text) and a download button.

## On a channel without UI

The file itself, attached after the reply's text, by its extension: an image as a picture, audio as a voice note, video as a video, anything else as a document. A file that can't be sent (none at that path, outside the workspace, over 15 MB) is said in a line instead: "(path couldn't be sent: reason)".
